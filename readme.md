JavaScript Array and Function Operations
What is this project?
This project contains simple JavaScript functions that work with arrays. An array is just a list of numbers. These functions help you find useful information from that list.

What does it do?
The project has 3 main functions:

Find the Maximum Number – Looks through the array and tells you the biggest number.
Calculate the Sum – Adds up all the numbers in the array and gives you the total.
Count Odd Numbers – Counts how many numbers in the array are odd (like 1, 3, 5, 7...).

How to use it?

A dummy (sample) array is already included for testing, so you don't need to create your own data.
Just run the JavaScript file and all results will be printed in the Console (using console.log).

How to run?

Open the project in any code editor (like VS Code).
Run the JavaScript file using Node.js:

node index.js

Check the console/terminal — you will see the results printed there.

Example Output
Maximum Number: 95
Sum of all elements: 450
Count of Odd Numbers: 6

Who is this for?
This is a beginner-level JavaScript assignment. It's great for anyone learning how to:

Write functions in JavaScript
Work with arrays
Use console.log to display results
